WANDER STATIC WEBSITE
======================

使用方式
1. 將整個資料夾上傳到網站主機。
2. index.html 是唯一需要執行的網頁。
3. images/ 放網站圖片。

換圖片
-------
請保留原本檔名，直接用新圖片覆蓋 images/ 裡的同名檔案即可，例如：
images/hero.jpg
images/milano.jpg
images/bergamo.jpg
images/como.jpg
images/genova.jpg
images/portofino.jpg
images/ventimiglia.jpg
images/nice-oldtown.jpg
images/nice-promenade.jpg
images/villefranche.jpg

如果要使用不同檔名：
打開 index.html，搜尋「📸 圖片設定區」，修改 IMAGE 裡對應的檔名。

網站不需要：
- Lovable
- React
- Vite
- Node.js
- npm
- Firebase

備註
----
Google Fonts 會從網路載入 Noto Sans TC / Noto Serif TC；若離線，會自動使用系統備援字型。
