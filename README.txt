WANDER STATIC WEBSITE
======================

使用方式
1. 將整個資料夾上傳到網站主機或本地直接雙擊 index.html 即可瀏覽。
2. index.html 是唯一需要執行的網頁。
3. 根目錄存放 41 張完全不重複的景觀與飯店照片，絕無任何共用圖片。

自動佔位符備援機制
------------------
網頁內建精緻的品牌 SVG 佔位卡片機制：若任何圖片尚未放妥或暫時遺失，瀏覽器會自動呈現帶有米白/深海藍/暖金配色的標籤佔位圖，清楚顯示該景點中文名稱、類別與建議比例，不會出現破圖圖示。

網站特性：
- 純靜態網頁（Vanilla HTML / CSS / JS），不依賴任何外部框架或伺服器環境。
- Google Fonts 於有網路時自動載入 Noto Sans TC / Noto Serif TC，離線時自動回退系統備援字型。
